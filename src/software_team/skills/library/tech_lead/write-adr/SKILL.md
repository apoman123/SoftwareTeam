# Write an ADR

Capture each significant decision as a short **Architecture Decision Record**:

- **Title**
- **Status** (proposed / accepted / superseded)
- **Context** — the forces at play.
- **Decision** — what was chosen.
- **Consequences** — resulting trade-offs, good and bad.

Keep **one decision per ADR** so it stays focused and reviewable.
