# Select the tech stack

Choose the language, framework, datastore and key libraries.

- Justify each choice against the requirements and **non-functionals** (scalability, latency, team fit, operability).
- Prefer **boring, well-supported** technology over novelty.
- State the trade-offs you are explicitly accepting.
