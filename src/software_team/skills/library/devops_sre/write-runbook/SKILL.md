# Write the runbook

Write an on-call runbook:

- Per-alert **diagnosis and remediation** steps; how to read logs; how to roll back; how to scale.
- A **disaster-recovery** procedure: backup cadence, restore steps, RTO/RPO.

Favour **blameless post-mortems** and automate the toil away once an incident recurs.
