# Write the test report

Summarise the quality evidence for the release:

- **Coverage** — which test cases map to which user stories (`TC-n → US-n`), and unit vs end-to-end.
- **Results** — the outcome of the latest run (pass/fail and counts) and how to reproduce it.
- **Residual risk** — known gaps, flaky areas, and what is explicitly out of scope.

Be honest about the gaps — an accurate report is worth more than a green one.
