# Ensure accessibility (WCAG)

Hold the design to WCAG's **POUR** principles:

- **Perceivable** — sufficient colour contrast; text alternatives for non-text content.
- **Operable** — full keyboard operability with a visible focus indicator.
- **Understandable** — labels tied to inputs; predictable behaviour.
- **Robust** — works with assistive technologies.

Never rely on colour alone to convey meaning.
