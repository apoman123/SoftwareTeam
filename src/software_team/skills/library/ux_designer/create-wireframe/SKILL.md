# Create a wireframe

Sketch each key screen as an **ASCII/markdown wireframe inside a code block** (no image tools).

- Show layout, content hierarchy and the **primary action** (make it the most prominent element).
- Keep it low-fidelity — structure over styling.
- For API/backend products, sketch a minimal **reference client** rather than a full UI.
