# Apply Nielsen's usability heuristics

Evaluate the design against Nielsen's 10 heuristics, especially:

- **Visibility of system status** — always show what is happening.
- **Match the real world** — use the user's language.
- **User control & freedom** — provide undo/cancel.
- **Consistency & standards.**
- **Error prevention**, then clear, plain-language, recoverable **error messages**.
- **Recognition over recall** — keep options visible.

List any heuristic the design violates and how to fix it.
