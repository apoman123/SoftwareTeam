# Map the user flow

Map the primary journey as a **numbered, end-to-end flow** from entry point to goal completion.

- Call out **decision points** and **alternate / error paths**.
- Keep the happy path short — minimise steps and required inputs to reach value.
- For an API/backend product, describe the journey of the consuming client instead of screens.
