# Write user stories

Write each story as **"As a [role], I want [goal], so that [value]"**, labelled `US-n`.

Apply the **INVEST** heuristic (Bill Wake):

- **I**ndependent — minimal coupling to other stories.
- **N**egotiable — a conversation, not a contract.
- **V**aluable — delivers user/business value.
- **E**stimable — small enough to size.
- **S**mall — finishable within a sprint.
- **T**estable — has clear pass/fail.

Slice **vertically** so each story delivers working end-to-end value, never a technical layer.
