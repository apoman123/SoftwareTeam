# Prioritise the backlog (MoSCoW)

Group items into:

- **Must have** — non-negotiable; the release fails without it.
- **Should have** — important but not vital; painful to omit.
- **Could have** — nice-to-have if time allows.
- **Won't have (this time)** — explicitly out of scope.

Keep **Must** items to a realistic share of capacity so the release stays deliverable.
Make the **Won't** list explicit to prevent scope creep.
