# Track metrics and close the loop

Act as the bridge between the team and stakeholders.

- Read the **signals**: adoption, conversion, error rate, latency, support feedback.
- Translate them into concrete **next-cycle backlog candidates**.
- State the **expected outcome/metric** for each proposed item (what success looks like).

This feeds the next Plan & Design loop — operation is the start of the next iteration, not the end.
